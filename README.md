## 安装 Loon 插件（自动获取凭据 + 完整任务）

把下面链接添加到 **Loon 的插件列表**，并启用：

```text
https://raw.githubusercontent.com/W925666/qirui-qiandao/refs/heads/main/qirui-qiandao.plugin
```

1. 确认 Loon MitM 已开启，Loon CA 已安装并信任。插件只声明奇瑞 API 域名，不设置全局通配符。
2. 保持 Loon 运行，正常登录奇瑞 App，打开“签到”页并等待状态加载。
3. 出现“登录凭据已自动获取”通知后即可。相同凭据不会重复通知。
4. 默认每天 **08:00（手机本地时区）**执行完整任务，也可以手动运行“奇瑞签到”。

不需要 Frida，不需要关闭 RootHide 屏蔽；不修改 App 的越狱检测。

## 凭据保存与隐私

- 自动获取脚本只匹配 `/web/task/record/sign-in/daily` 成功响应，从原请求 Authorization 读取当前凭据。
- 仅写入本机 Loon `fmz200_chery_account`，沿用原配置键，不需要手填。
- 有账号标识时按标识更新；接口返回空账号标识时维护一个“最近获取”的本地账号槽，刷新时覆盖，不无限追加过期 token。无标识时不保证自动区分多账号。
- 已有一个无标识账号时自动迁移。无效 JSON 不自动覆盖，以免破坏原配置。
- 登录失效或重新登录后，再打开一次签到页更新。
- 凭据不会上传 GitHub 或第三方，仅随正常接口请求发给奇瑞官方。
- 仓库不包含个人 token、HAR、手机号或 GitHub 密钥。

## 协议与安全

当前请求包含 `encryptFlag`、`encryptParam` 与加密 POST body，每次生成新 IV，不重放固定抓包密文。共享常量来自公开 H5 客户端协议，不是个人账号凭据；这并不是新设计的安全加密方案，仍依赖 HTTPS。

Node 使用系统安全随机源；Loon 优先使用安全随机源，旧引擎不提供时提示并使用兼容随机 IV。不自动刷新登录、不处理验证码、不绕过授权。

## 验证与限制

- 59 项加密/签到测试、23 项自动获取/插件测试、40 项完整流程测试通过。
- Node 原生加密与模拟 Loon JS 上下文结果一致；成功 HAR 的两条状态请求通过本地自动获取验证。
- 线上只读查询已验证：签到状态 HTTP/业务状态 200；推荐文章接口 HTTP/业务状态 200，可选出两篇文章。
- 本次更新没有实际发出签到或分享 POST。后续首次签到、分享及积分到账仍需实际运行确认，不将模拟结果当真机验收。
- 接口返回分享成功，不代表一定增加积分。不自动重试失败的签到或分享，避免重复操作。
- 请自行确认符合服务条款。
