# 奇瑞签到

Loon 自动获取本机登录凭据 + 加密协议签到。**不用手填 token，仓库不保存个人 token。**

## 安装

将下面的链接添加到 Loon 插件中，并启用插件：

```text
https://raw.githubusercontent.com/W925666/qirui-qiandao/main/qirui-qiandao.plugin
```

1. 确认 Loon 的 MitM 已开启，Loon CA 证书已安装并信任。插件仅声明奇瑞 API 域名，不设置全局通配符。
2. 保持 Loon 运行，正常登录奇瑞汽车 App，进入“签到”页面，等待状态加载。
3. 收到“登录凭据已自动获取”通知后即可。相同凭据再次获取不会重复通知。
4. 默认每天 **08:00（手机本地时区）**自动运行。也可以在 Loon 中手动运行“奇瑞签到”任务。
5. 请停用旧版重复的奇瑞签到定时任务，避免两套脚本同时执行。

**不需要 Frida，不需要关闭 RootHide 屏蔽，不修改 App 的越狱检测。**

## 脚本直链

- 签到：`https://raw.githubusercontent.com/W925666/qirui-qiandao/main/chery-sign.js`
- 自动获取凭据：`https://raw.githubusercontent.com/W925666/qirui-qiandao/main/chery-capture.js`

只添加签到脚本、没有添加获取凭据脚本时，脚本不会凭空获得账号。建议直接安装上面的完整插件。

## 凭据如何保存

- 获取脚本仅匹配 `/web/task/record/sign-in/daily` 的成功响应，从原请求 Authorization 读取当前登录凭据，结合响应中的账号标识保存。
- 仅写入当前设备 Loon 的 `fmz200_chery_account` 本地存储，与旧配置键保持兼容。
- 登录凭据不会上传到 GitHub，也不会发到任何第三方地址；签到时只发给奇瑞官方 API。
- 支持按账号标识更新凭据，并对重复 token 去重。旧版只有一个无标识账号时自动迁移。
- 存储内容不是有效 JSON 时不会自动覆盖；需要先在本地修复或清除该配置。
- 会话失效或重新登录后，再打开一次签到页更新即可。不实现自动登录、验证码处理或授权绕过。

## 签到逻辑

先查询今日状态 → 已签到则跳过 → 未签到只提交一次 → 再查询确认。

当前协议包含 `encryptFlag`、`encryptParam` 和加密请求体；每次请求重新生成 IV，不重放某次抓包的固定密文。此版本**只执行签到，不自动分享文章**。

官方 H5 中的固定共享加密常量不是个人账号凭据，不应视为一套新的安全加密设计；仍依赖 HTTPS。Node 使用系统安全随机源，Loon 优先使用可用安全随机源，旧引擎不提供时会提示并使用兼容随机 IV。

## 验证与限制

- 已通过 Node 语法检查和离线协议测试。
- Node 原生加密与模拟 Loon JavaScript 引擎测试结果一致。
- 已对本人提供的成功抓包完成本地协议复现，抓包文件未上传。
- 已进行一次只读状态查询，返回成功；没有重复发起签到或分享请求。
- 插件尚需在真实 Loon 中导入验收，不能把离线模拟等同于完整真机测试。
- 后续首次未签到时的 POST 仍需实际运行验证。接口变化、会话失效或 App 的 HTTPS 策略变化都可能影响运行。
- 使用前请确认符合服务条款；不保证签到奖励或积分到账。
